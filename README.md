
# Local Politics Tracker — RAG Application

## Overview
Local Politics Tracker is a Python-based project exploring how Retrieval-Augmented Generation (RAG) can help users retrieve and explore political information.

## Problem Statement
Political information may be spread across different documents and sources. This project explores how document retrieval and language models can help users find relevant information efficiently.

## Objectives
- Organize political information for retrieval.
- Retrieve relevant context from available documents.
- Explore embeddings and vector search.
- Generate context-aware answers using retrieved information, where supported by the implementation.

## Technologies
- Python
- Retrieval-Augmented Generation (RAG)
- Embeddings and vector search
- Large Language Models (LLMs)

## Project Structure
- `src/` — Python source code.
- `requirements.txt` — Python dependencies.
- `.gitignore` — Excludes specified local and sensitive files.

## How RAG Works
1. Load source documents.
2. Split text into chunks.
3. Generate embeddings.
4. Retrieve relevant chunks for a question.
5. Use retrieved context to support a response.

## Setup
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install dependencies using `pip install -r requirements.txt`.
4. Configure the required API credentials locally.
5. Follow the application's actual entry-point instructions.

## Responsible Use
AI-generated answers may be incomplete or inaccurate. Verify important political claims against reliable original sources.
